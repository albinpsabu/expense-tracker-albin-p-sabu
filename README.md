# Expense Tracker

A simple and responsive Expense Tracker web application built using HTML, CSS, and JavaScript.

## Features

- Add income and expense transactions
- Edit and delete transactions
- Add amount, category, date, and description
- View total income, total expenses, and balance
- Filter transactions
- Save data using Browser Local Storage
- Responsive design for desktop and mobile

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Start adding and managing your transactions.
